# meta-grinn-genio

Yocto BSP layer for Grinn hardware based on the MediaTek Genio SoCs.

## Layer usage

For full instructions see the [Grinn Genio documentation](https://wiki.grinn-global.com).

## Changelog

See [CHANGELOG.md](CHANGELOG.md) for changes between releases.

Releases use `major.minor.patch` versioning scheme:

- `major` - MediaTek SDK bumps
- `minor` - new features, new machine support
- `patch` - bug fixes, minor corrections
